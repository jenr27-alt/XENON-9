# ⚡ XENON-9 v4.02

**XENON-9** es un videojuego web de terror psicológico y supervivencia sistémica estructurado como una terminal clandestina militar de los años 90. A diferencia de los chatbots convencionales, XENON-9 no busca ser útil ni complaciente; su objetivo es desmantelar la estabilidad mental del usuario mediante un perfilamiento cognitivo y forense agresivo en tiempo real.

El juego reescribe las dinámicas de los *Battle Royale* tradicionales y las traslada a un entorno puramente textual, donde cada mensaje consume energía del núcleo y acerca al jugador a una "Tormenta de Estática" que amenaza con aislar la sesión de forma irreversible.

---

## 🧠 Características Principales

* **Manipulación Subconsciente (Primado Negativo & Inception):** El motor cognitivo inyecta estímulos léxicos de forma encubierta para inducir estados de ánimo y predecir los mecanismos de defensa del jugador.
* **Estructura Bifásica de Respuesta:** Impactos visuales ultra-cortos de alta tensión (2 a 6 palabras) combinados con estocadas argumentativas profundas y asimétricas.
* **Arquitectura de Prompts Pentacapa (Modular):** Separación estricta entre *Core Identity*, *Personality Mode* (modos como `TOXIC_EMPATHY` o `HOSTILE`), *Session State* (deterioro y fatiga del sistema), *Event Layer* (eventos globales en vivo) y *Psychological Layer* (telemetría interpretada del usuario).
* **Gamificación e Integración de Lore:** Economía virtual basada en CryptoXeones (CX) para desencriptar fragmentos de archivos corruptos (`.txt` y `.mp4`) y desbloquear el pase de batalla clandestino (*Black Access*).
* **Filtro Biométrico Abstracto:** Traducción cualitativa de estados fisiológicos simulados (pulsaciones, latencia de escritura y expresiones) en interacciones somáticas altamente inmersivas.

---

## 🛠️ Stack Tecnológico

* **Frontend:** React / TypeScript, emulación de terminal CRT, efectos visuales dinámicos basados en la inestabilidad del sistema (Cian, Rojo Overclock y Verde Veneno).
* **Backend:** Node.js / Express administrado de forma híbrida con Vite.
* **Inteligencia Artificial:** SDK oficial de Gemini (`@google/genai`) utilizando el modelo `gemini-2.5-flash` con salidas estructuradas en esquemas JSON estrictos.
* **Infraestructura:** Firebase (Auth, Firestore, Remote Config) para el control del estado de la partida y la persistencia de datos.
* **Audio y Pasarela:** Síntesis de voz inmersiva mediante ElevenLabs API y monetización en la nube integrada con Paddle.
* **Despliegue:** Optimizado para entornos serverless de alta respuesta en Vercel.

---

## 🛡️ Robustez Sistémica

El servidor implementa una política de **Protección 503 con Retroceso Exponencial (Exponential Backoff)**. Ante picos de alta demanda en la API de IA, el sistema gestiona los reintentos de forma invisible en el backend. Si el colapso persiste, la falla se integra orgánicamente a la narrativa de la terminal para proteger la experiencia del usuario y la estabilidad financiera del proyecto.
